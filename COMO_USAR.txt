2. Mantenha imagem/image.png, as bibliotecas e os Secrets atuais.
3. Teste: http://localhost:8501/?visao=sem-checkin
4. Nesse link, somente unidades com COD_LOJA de 001 a 068 aparecem; as unidades 552 (CSC), 700 (darkstore) e CDs 988/989/993/995/996/998/999 ficam fora.
5. Os 4 KPIs também são recalculados considerando somente lojas.
6. O link normal (sem ?visao=sem-checkin) permanece inalterado, incluindo CDs.
7. Para publicar: git add app.py && git commit -m "Filtra somente lojas no link compartilhavel" && git push origin main

Regra: foram encontrados os códigos de lojas 001–068 na base Auto NF fornecida. Se futuramente surgirem lojas com códigos superiores a 068, atualize o intervalo de códigos nessa função.
